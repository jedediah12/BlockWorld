# BlockWorld

Playable BlockWorld web prototype.

How to use:
1. Open `index.html` in a browser or host on any static web host (GitHub Pages, Netlify, Vercel).
2. Controls: Arrow keys or WASD. On mobile use the on-screen touch buttons.
3. Click Restart to restart the game.

Notes:
- I created this repo and added the playable `index.html`.
- To publish with GitHub Pages: in the repository Settings → Pages, set the source to the `main` branch and `/ (root)` folder, save, and wait a minute for the site to appear at `https://jedediah12.github.io/BlockWorld/`.
